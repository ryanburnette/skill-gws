# skill-gws — agent pointer

This directory is a **living, portable skill** for the gws CLI. It is not a
host runbook and it must not identify a particular person or machine.

1. Read **[SKILL.md](./SKILL.md)** and the topic files it maps.
2. When you learn something reusable, add it here. Prefer small topic files.
   Keep examples generic.
3. Host/project facts (accounts, paths, logs, plans) live in the consuming
   project, not here.
